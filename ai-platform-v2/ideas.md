# AI中台二期原型设计理念

## 选定方案：医疗科技精密中台风格

**设计运动**：精密医疗科技中后台（Medical-Tech Precision Dashboard）

**核心原则**：
1. 信息层级清晰——首要指标突出，次要信息克制，操作区域明确分区
2. 蓝白主调，深蓝锚定权威感，浅蓝营造科技感，白色保证可读性
3. 卡片化信息单元，每个卡片有明确边界、标题、数据和操作，避免信息堆砌
4. 状态可视化——运行中/已发布/异常/草稿等状态用色块标签清晰区分

**色彩哲学**：
- 主色：#1B4FD8（深蓝，权威、专业）
- 辅色：#3B82F6（中蓝，交互、链接）
- 强调：#0EA5E9（天蓝，数据高亮）
- 成功：#10B981（青绿，在线/正常）
- 警告：#F59E0B（琥珀，待处理）
- 危险：#EF4444（红，异常/失败）
- 背景：#F0F4F8（极浅蓝灰，区分于纯白卡片）
- 卡片：#FFFFFF

**布局范式**：
- 固定左侧导航（240px宽），顶部标题栏（56px高）
- 主内容区三段式：顶部指标卡行 → 中部主体内容 → 底部辅助信息
- 表格行高48px，表头深色背景，行间隔斑马纹

**标志性元素**：
1. 左侧导航：深蓝渐变背景，白色图标文字，选中项浅蓝高亮条
2. 指标卡：白色卡片，顶部彩色边框线，大号数字，小号趋势箭头
3. 状态标签：圆角胶囊形，填充色+白色文字

**字体系统**：
- 中文：PingFang SC / Noto Sans SC
- 数字：Tabular nums，保证对齐
- 标题：font-semibold 16-18px
- 正文：font-normal 14px
- 辅助：font-normal 12px，muted颜色
